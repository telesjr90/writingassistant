# PHASE8-IMPL-006 BookNLP-Ready Raw Output / Adapter Contract Decision

## 1. Decision Summary

`PHASE8-IMPL-006` will define a BookNLP-ready adapter contract before runtime extraction.

Accepted direction:

- Raw BookNLP-like outputs remain raw support artifacts, not candidates and not canon.
- BookNLP-like output must map through app-owned source locators, evidence records, and normalization before becoming Writer Assistant Core candidates.
- T005 does not install or run BookNLP.
- T005 does not implement adapter code.
- T005 does not create runtime project files.
- T006 will add tests using mocked fixture structures only.
- Owner review remains mandatory.
- No raw output, high confidence, quote attribution, entity cluster, or event tag becomes project truth automatically.

## 2. Why This Decision Exists

`PHASE8-IMPL-006-T001` revised the parent to evidence-first and BookNLP-ready. `PHASE8-IMPL-006-T002` accepted source-map and evidence contracts. `PHASE8-IMPL-006-T003` added tests for source-map/evidence helpers. `PHASE8-IMPL-006-T004` implemented pure validation helpers.

BookNLP is a strong candidate for a later literary extraction adapter, but only after raw output boundaries and normalization rules are clear. T005 gives T006 a precise test contract without running BookNLP.

## 4. Raw Artifact Type Contract

Supported future BookNLP-like raw artifact kinds:

- `booknlp_tokens`
- `booknlp_entities`
- `booknlp_quotes`
- `booknlp_book_json`
- `booknlp_supersense`
- `booknlp_events`

Optional generic/support artifact kinds:

- `booknlp_html`
- `booknlp_manifest`
- `mock_fixture`
- `other_raw_output`

### `booknlp_tokens`

Role:

- token-level alignment support
- source-map/token-offset bridge
- sentence/paragraph/document position support
- evidence-span reconstruction support

Not allowed:

- canon
- candidate by itself
- generated prose
- memory/canon mutation

### `booknlp_entities`

Role:

- support for possible character, organization, location, object/item, and entity mention candidates
- support for alias/coreference candidate evidence if present in raw data

Not allowed:

- automatic character truth
- automatic relationship truth
- automatic approved memory

### `booknlp_quotes`

Role:

- support for quote evidence
- possible dialogue quote candidate support
- possible speaker attribution candidate support

Not allowed:

- automatic speaker truth
- automatic dialogue canon beyond source text
- generated dialogue

### `booknlp_book_json`

Role:

- aggregate metadata support
- possible character cluster/support summary reference
- source for candidate support only

Not allowed:

- canon authority
- automatic story bible update
- automatic character roster truth

### `booknlp_supersense`

Role:

- optional semantic support
- possible object/action/concept signal support

Not allowed:

- automatic Subtxt/Dramatica label
- automatic conflict/storyform truth

### `booknlp_events`

Role:

- possible event/action candidate support
- possible timeline signal support if source locators are reliable

Not allowed:

- automatic timeline canon
- automatic causal chain truth
- automatic plot truth

## 5. Raw Output Storage Policy

Future storage root:

```text
projects/{project_id}/writer_assistant/extractions/booknlp/{run_id}/
```

Future files:

- `manifest.json`
- `raw/tokens.tsv`
- `raw/entities.tsv`
- `raw/quotes.tsv`
- `raw/book.json`
- `raw/supersense.tsv`
- `raw/events.tsv`
- `raw/book.html` if generated by the tool and if future policy allows storing it
- `normalized/normalization_report.json`
- `normalized/candidate_drafts.json` if a future parent authorizes it

Decisions:

- T005 does not create these paths.
- Raw output storage paths are future-only.
- Raw outputs are not canonical truth.
- Raw outputs are not candidate JSON.
- Raw outputs are not approved memory.
- Raw outputs are not training data.
- Raw outputs must remain under `writer_assistant/extractions/booknlp/{run_id}/`.
- Raw outputs must never be written to `memory/`, `canon/`, `bible.json`, `storyform.json`, `scenes/`, `notes/`, `materials/`, or owner-authored source files.
- Raw outputs may be deleted/rebuilt without changing approved truth.
- Raw output references must use `artifact_path_hint` as display/debug metadata only.
- Future implementation must use safe path helpers and reject traversal/absolute paths.
- T005 does not create raw storage helpers.

## 9. Adapter Normalization Boundary

Accepted future pattern:

```text
owner-authored source snapshot
-> source map
-> future BookNLP raw artifacts
-> raw output references + run manifest
-> app-owned adapter normalization
-> evidence records
-> Writer Assistant Core candidate records
-> candidate persistence/index
-> owner review
```

Rejected patterns:

```text
BookNLP raw artifact
-> memory/canon
```

```text
BookNLP raw artifact
-> storyform truth
```

```text
BookNLP raw artifact
-> generated prose or rewritten source
```

```text
BookNLP character cluster / quote attribution / event tag
-> approved truth without owner review
```

Normalization rules:

- Adapter must validate source locators before creating evidence.
- Adapter must validate evidence before creating candidates.
- Adapter must validate candidate records before persistence.
- Adapter must preserve raw artifact provenance.
- Adapter must attach source snapshot hashes.
- Adapter must fail closed when offsets are missing or inconsistent.
- Adapter must produce insufficient-evidence or rejected-output records rather than guessing.
- Adapter must not create memory/canon writes.
- Adapter must not call models.
- Adapter must not generate prose.

## 11. Error and Fail-Closed Policy

Future adapter must reject or quarantine raw outputs when:

- source snapshot hash is missing
- source document reference is invalid
- source locator is missing
- offset spans are invalid
- text excerpt does not match source snapshot if future helper checks it
- raw artifact kind is unknown
- run manifest is invalid
- artifact hash is missing
- raw output attempts canon/memory mutation
- raw output includes generated prose fields
- candidate type is unsupported
- evidence cannot be attached
- confidence is missing or invalid
- attribution/coreference/event output is ambiguous and no owner-review path exists

Fail-closed outputs may become:

- validation error
- rejected raw output entry
- insufficient-evidence candidate
- adapter warning
- no candidate

They must not become canon.
