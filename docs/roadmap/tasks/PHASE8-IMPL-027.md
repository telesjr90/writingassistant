It activates only after PHASE8-IMPL-025 and PHASE8-IMPL-025-T012 are complete
and passing. It does not replace or reopen historical closeout evidence.

## Goal

Prove the current application as a genuinely usable, repeatable, owner-tested
MVP and publish the authoritative closeout. This is not another automated test
suite and does not authorize application implementation in this planning task.

## Required acceptance evidence

- current application version and real owner project data;
- browser-to-HTTP live invocation through the owner workflow;
- every required available live runtime, with fixture-only, deferred,
  unavailable, and owner-blocked tools listed explicitly;
- installation, supported-version, discovery, configuration, compatibility,
  and preflight matrix;
- validated raw artifacts and hashes, manifests, evidence ledgers, provenance,
  and candidate-only output;
- failure, timeout, unavailable, partial-result, retry, and recovery paths;
- clean browser console and network evidence, accessibility checks, and
  responsive checks;
- filesystem diff proving no unauthorized mutation;
- no generated prose, automatic promotion, automatic apply-promotion, or
  automatic Memory/Canon mutation;
- limitations and support evidence;
- explicit owner accept, reject, or defer decision;
- authoritative closeout publication and mandatory final Project Memory
  refresh.

External dramatica-flow remains owner-blocked unless its separate accepted
reopening conditions are later met. The app-owned rubric remains a distinct
capability. Candidate review, promotion, and apply-promotion boundaries remain
explicit, audited, isolated, and owner-controlled.
